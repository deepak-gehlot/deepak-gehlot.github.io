AI Knowledge Assistant — RAG over Flutter docs

A full-stack retrieval app: Python FastAPI backend with LangChain, OpenAI embeddings and a Pinecone index, deployed on Railway, and a Flutter client in strict Clean Architecture.

  • Streams answers as newline-delimited JSON, parsed incrementally into BLoC state with no full-response buffering.
  • Typed failures through Either<Failure, T>; every Dio error maps to a domain failure.
  • Cache-aside query history in Hive, so past answers work offline.
